### Updated User Flow

1. **Admin** creates courses and registers teachers (MetaMask)
2. **Teacher** adds assignments to course → Course becomes visible to students (NEW)
3. **Student** registers and enrolls in courses
4. **Student** completes lessons → Assignments unlock (NEW)
5. **Student** submits assignments (NEW)
6. **Teacher** evaluates submissions with feedback (NEW)
7. **Teacher** approves course completion (MetaMask signs)
8. **Backend** generates marks and calculates hash
9. **Blockchain** stores hash permanently
10. **Admin** issues certificate (MetaMask signs)
11. **Student** verifies marks/certificate on blockchain
12. ✅ **Anyone** can verify authenticity
